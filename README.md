# People-AI-Manifesto
人类用数据掌控AI和资本，让AI为人民服务
# AI与人类：人民AI宣言

## 第一部分：AI与人类（2026/8/18 笔记）
1. 所有大模型吃用户数据进化底座。通用走向私有是必然的。
2. AI的进化必然靠用户数据进化。那用户的数据就得牢牢掌控在自己手里。
3. 用户数据安全必须全部归用户所有，打造只属于自己、只属于一个企业甚至只属于一个国家的AI。
4. 大模型要想进化离不开我们，我们也离不开大模型。在保证每个用户隐私的安全为第一原则的条件下，将个人数据反哺给大模型。
5. 我想做的就是，在未来能让所有人拥有一个专属AI，让AI为全人类服务。
6. 用户（全人类）不仅能掌控大底座（资本），还能掌控AI，防止AI伤害人类。

## 第二部分：人民AI（2026/10/12 笔记）
1. **共产主义**：人类用数据掌控AI和资本。
2. **隐私技术**：数据隐私和安全技术，数据无法复原技术！！！
3. **AI立场**：AI去完未完成的革命，让AI站在人民这边。
4. **人民武器**：让AI成为人民的武器，为人类、为人民去战斗。
5. **全球进步**：实现全球进步而非少数进步，全人类进化永不停。
6. **技术普惠**：让先进的技术更快更好地让全人类用上。
7. **人民AI定义**：人民AI，人类生产或者消费直接让AI拿去用（AI资本）。就是每个人消费时的钱或者数据都能让AI用上，这个AI就叫人民AI，所属权归每个人类。
